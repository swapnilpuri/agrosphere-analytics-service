Invalid UTF-8/Unicode scalar sequences/BOM/duplicate keys/unknown fields/non-finite numbers or unsupported type/version reject. Boundary fixtures must prove valid full adjusted/void envelopes fit; if the reviewed schema can exceed a ceiling, stop and revise rather than silently drop valid input.

Fingerprint algorithm `ANL_JSON_DECIMAL_V1`: SHA-256 of a deterministic typed encoding of the complete validated JSON value, excluding AMQP transport headers. Null=`Z`, booleans=`T`/`F`; numbers=`N` + exact BigDecimal plain normalized value + `;` (strip trailing zeros, zero=`0`). Strings=`S` + UTF-8 byte length in ASCII + `:` + exact UTF-8 bytes, without Unicode normalization. Arrays=`A` + element count + `:` + concatenated child encodings. Objects=`O` + member count + `:` + each key string encoding/value encoding in ASCII key order (all accepted schema keys are ASCII). Array order and string content, including timestamp string spelling, remain significant. No binary floating conversion or field omission. Test whitespace/key-order/numeric-equivalence duplicates and changed ignored-personal-field conflicts; never persist raw personal fields to establish a fingerprint.

Valid REAL input produces only minimal receipt/unsupported issue evidence and zero contribution; raw envelope is discarded. Full bodies, actors, worker IDs, reasons and measurement evidence never appear in application logs, projection tables or diagnostic payloads. Malformed input has no trusted scope: keep only body SHA-256/reason code in private diagnostics, not inferred estate identifiers.
