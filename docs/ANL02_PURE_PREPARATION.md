`EnvironmentalObservation` preserves minimal immutable SIMULATED facts from a future fully validated TelemetryObservationRecorded v1 envelope: event/observation/device/scope identities, complete validated-envelope SHA-256, exact original value string, kind/unit, observed/received times and rain interval. Decimal scale and measured zero remain source evidence; no normalization, averaging, rainfall summation or cross-device aggregation. Years 0001–9999, UTC millisecond precision, percentage/rain constraints and five-minute observed/received skew match Telemetry semantics. Its constructor does not prove full-envelope validity or compute a fingerprint. Unsupported types, versions, source, provenance, aggregate identity and envelope/payload consistency must be rejected by the separately reviewed future parser before this boundary.

`EnvironmentalProjection` applies immutable facts, receipts and minimal scoped conflicts. Identical event/content is a no-op, including repeated rejected observation-ID reuse. Same event ID with changed full fingerprint/minimal content, or another event claiming an existing observation ID, preserves the original fact. Issues count distinct offending event IDs per affected trusted block, including both blocks when validated identity changes scope; retries do not increase counts. Reconciliation/issue clearing is outside preparation. No invented versions, updates or cancellation semantics.

Rebuild reads immutable facts, never source SQL or raw envelopes. Queries require explicit positive [from,to) of at most 24 hours, filtering observedAt, retaining receivedAt separately and preserving rain intervals even when they begin before from. Sort by instant then canonical UUID text (not Java's signed UUID order); first 1000 rows, exact decimal integer total count and returned counts for all three kinds. NONE means no matching observed facts; zero is an actual returned value. OBSERVED_ONLY never proves device/estate/stream completeness. Any block-wide unresolved conflict yields INCOMPLETE even if outside the selected window. Scope-wide lastProcessedAt/latestSourceEventAt are inspected metadata, not consumer watermarks. Invalid/admission diagnostics lack trusted scope and cannot be represented as block issues here.

`ReadEnvironmentalHistory` enforces the existing global admin or assigned estate admin/manager/auditor matrix before active-block access and projection ports. Dependency failure propagates; no empty-success fallback. This is a pure access test, not signed-JWT/delegated HTTP verification. New ports have no adapters or Spring registration.

Run JDK 25 `mvnw.cmd verify` and `python scripts/validate_contract_pins.py --jar target/agrosphere-analytics-service-0.1.0.jar`. Nine new tests cover windows, exact values/intervals/devices, malformed values/units/skew, duplicate/fingerprint/reuse/cross-scope conflict, scope-wide issues outside window, canonical ordering/count/cap, all six delivery orders with duplicates, immutable state, access-before-dependencies and failure propagation. Full pure/view rebuild is in memory; it is not a database scalability or recovery claim.
