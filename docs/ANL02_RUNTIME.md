# ANL-02 environmental history runtime

The owner accepted the exact runtime/SQL package in Architecture `ANALYTICS_ENVIRONMENT_ADAPTER_APPROVAL.md`. Contracts 0.12.0 and the unchanged Telemetry v1 input are independently pinned. Original review/manifest/SQL candidate bytes remain unchanged; historical pending labels are superseded by the approval. [SQL/grant engineering review](ANL02_SQL_ENGINEERING_REVIEW.md) preceded installation in disposable fixtures.

Environmental history is disabled by default. `ANALYTICS_ENVIRONMENT_ENABLED=true` is eligible only with `ANALYTICS_DEMO_ENABLED=true`, a rechecked short-lived ownership manifest/hash and database marker. The manifest binds database URL and migration/runtime identities, a separate environmental broker principal, exact private queue, reviewed V3 hash, source scopes and an explicit rebuild window. The fixture expires within two hours. Environment credentials are generated only by the owned Infrastructure drill; no existing private environment file or target is accepted.

Default migration remains V1. Earlier generated ANL-01 activation targets V2; only the additional verified environmental gate selects V3. V1/V2 remain byte-identical. The environmental consumer owns a separate AMQP connection and queue; existing production topology/permissions remain unchanged. Runtime may SELECT/INSERT immutable receipts/observations/issues and SELECT/INSERT/UPDATE scoped metadata, with no historical mutation/DDL/TEMP/TRUNCATE. SQL errors roll back; confirmed commit precedes ACK. Diagnostic confirmation without mandatory return precedes terminal ACK. Four attempts with 1/2/4-second backoff end in an unacknowledged pause on uncertainty; explicit owned-fixture recovery only.

The strict parser validates the complete released closed Telemetry envelope, kind/unit/value/time/identity/provenance semantics and all oneOf branches before constructing minimal facts. `ANL_JSON_DECIMAL_V1` hashes every validated envelope field, including correlation ID. Exact admitted value text is retained without another normalization step; the Telemetry producer already normalizes its own incoming MQTT numeric spelling. Tests separately prove Analytics preserves any allowed source value string such as `-2.125000`. The actual producer drill compares every materialized value to its emitted source event, including actual `-2.125` and measured zero.

Finite generated admission remains 262144 UTF-8 bytes, depth 64, 10000 members/elements, numeric token length 1000 and absolute raw exponent 1000. Preflight precedes numeric expansion. ADMISSION_LIMIT and INVALID_ENVELOPE have no trusted scope/event ID and retain only full-body SHA-256/reason in private diagnostics. No raw-body DLQ/log/archive; diagnostics are not Gateway routes. This is not universal wire-encoding support or stream completeness.

One immutable observation per ID; matching full event fingerprint is a no-op. Changed event content or observation-ID reuse preserves the original fact and minimal issues in both affected trusted scopes. Count distinct offending event IDs block-wide, including outside query; narrowing cannot conceal them. No version-gap/update/cancel semantics, inferred device cadence or automatic issue reconciliation.

The GET `/api/v1/analytics/estates/{estateId}/blocks/{blockId}/environment/observations` requires explicit UTC millisecond from/to, positive [from,to) no longer than 24 hours. Repeated/unknown/missing filters fail 400. Existing signed issuer/audience/expiry/trusted role and estate matrix precedes active delegated Estate/block checks and the read. Disabled/expired/dependency state returns unavailable, never an empty success. A read-only repeatable-read snapshot returns first 1000 observed-time/canonical-ID ordered samples, exact decimal integer count, truncation, per-kind returned counts, source refs, and block-wide metadata/conflicts. Measured zero is a row; NONE means no matching facts, not zero weather/rain/coverage. OBSERVED_ONLY never certifies completeness; any unresolved trusted conflict yields INCOMPLETE. Rain intervals remain intact even when beginning before from and are never summed/prorated.

`OwnedEnvironmentalRebuildMain` has no public endpoint or arbitrary target/window: it rechecks manifest/hash/bindings/DB marker, reads the manifest window for allowed scopes, and reconstructs ordered views from its own immutable facts against the SQL view under repeatable-read and scope locking. No fact/receipt/issue mutation, source export, reset, repair or disaster-recovery claim.
